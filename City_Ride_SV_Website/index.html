PAGA COMO TE CONVENGA

Opciones de pago flexibles

El proyecto contempla diferentes alternativas para facilitar la reserva y el pago de cada viaje.

＄EfectivoPaga al abordar o al finalizar, según las condiciones del servicio.
▦Código QREscanea un código para completar el pago digital.
▣TarjetaUtiliza una tarjeta de débito o crédito mediante un proveedor seguro.
◈Billetera digitalConecta con medios de pago digitales disponibles.

Los pagos digitales se muestran como funcionalidades previstas; no se procesan transacciones reales en esta versión.
